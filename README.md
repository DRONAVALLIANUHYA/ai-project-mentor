\# ✦ AI Project Mentor



AI Project Mentor is an AI-powered web application that transforms a user's technology interest into a practical project blueprint.



It combines AI research, project planning, system architecture, database design, and a development roadmap in one workflow.



\---



\## 🚀 Features



\- 🔍 AI-powered technology research

\- 💡 Real-world project idea generation

\- 📊 Project evaluation and scoring

\- 🏗️ System architecture design

\- 🔄 Data-flow visualization

\- 🗺️ 4-week development roadmap

\- 💾 MySQL project history

\- 📚 Research resources

\- 🎯 Career-fit analysis

\- 🔐 API rate limiting

\- ⚠️ Centralized error handling

\- 📝 Application logging

\- ✅ Input validation
